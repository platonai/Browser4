## [0.1.0] – 2026-03-23

### Added
- Initial release of `@platonai/browser4-cli`.
- `session create` / `session close` commands for session lifecycle management.
- `tool <name> [key=value …]` command for calling Browser4 MCP tools.
- `--base-url` and `--session-id` global options.
- `Browser4Client` HTTP client class (also exported for library use).
