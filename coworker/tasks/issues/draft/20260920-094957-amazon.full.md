# B. Execution Trace

**Setup:** `./b4w.ps1 help`, read `SKILL.md`, and discovered a directly relevant scenario doc (`references/htmlsnapshot-scenarios-amazon.md`) — worth noting, since it is the source of two of the strongest findings.

**Commands and steps:**
1. `open --headless -s amazon-eval https://www.amazon.com/` → opened, but `page-info` showed an empty title. `eval` revealed an **AWS WAF challenge page** (`token.awswaf.com/challenge.js`, 1,995-byte HTML, empty `<body>`). `reload` + wait → still blocked.
2. Escalated per the SKILL's anti-bot rule: `close` → `open --headed` (same `-s`, profile preserved). **Navigation failed** with a raw CDP error; the workaround was `goto`, which refused ("Already at … — page unchanged"), then `reload`, which loaded Amazon in seconds.
3. **Search:** `fill e2640 "pens to draw on whiteboards" --submit` → succeeded on the first try (the docs predict this fails).
4. **Extraction attempt (documented path):** `htmlsnapshot inspect` → `query` with X-SQL. The doc's selectors matched nothing; `inspect` suggested only generic containers; and **every** X-SQL query timed out at 120s.
5. **Extraction (working path):** `eval --file` with card-scoped `querySelectorAll` produced aligned data; a follow-up `eval` dumped price-block HTML to disambiguate unit price vs. list price; a third verified no sponsored results in the first four.
6. Wrote the markdown deliverable; closed both sessions.

**Key decisions:** used a named session (`-s amazon-eval`) for isolation; treated the WAF block as a bot challenge rather than a network fault after confirming the host reached amazon.com in 2.4s via curl; aborted the X-SQL path only after a control test proved it broken on `example.com` too.

**Workarounds required:** headed mode instead of headless; `reload` instead of `goto`; `eval` instead of X-SQL; hand-discovered selectors instead of `inspect` output.

**Environment observation (not a browser4-cli issue):** the run's scratch dir `.test-sessions/20260920T0355347004286Z/` was not empty — it held ~60 artifacts from earlier runs (a `REPORT-DRAFT.md`, `product_index.json`, etc.).
