## C. Issues Found

### Issue 1: `b4w.ps1` fails with short flags on Linux/pwsh — `snapshot -i` intercepted by PowerShell

**Severity:** High

**Category:** Reliability

**Reproduction:**
```bash
./b4w.ps1 snapshot -i
```

**Expected:** Interactive snapshot captures, showing element refs for the form.

**Actual:**
```
b4w.ps1: Parameter cannot be processed because the parameter name 'i' is ambiguous.
Possible matches include: -InformationAction -InformationVariable.
```

**Root Cause:** `b4w.ps1` has a `param()` block with `[Parameter(ValueFromRemainingArguments = $true)][string[]]$RemainingArgs`. PowerShell's parameter binder processes `-i` before `$RemainingArgs` captures it, matching it against common parameters `-InformationAction` / `-InformationVariable`. The script attempts to handle this with `--` passthrough (line 48), but `--` is also processed by `param()` — `$RemainingArgs` receives `['--', 'snapshot', '-i']` and the `if ($RemainingArgs[0] -eq '--')` branch on line 48 strips it. However, `--` itself was initially parsed by PowerShell as an argument to the script's own `param()` block, causing "Parameter cannot be processed because the parameter name '' is ambiguous."

**Code Pointer:** `b4w.ps1:3-7` — the `param()` block. The `--` handling on lines 48-50 only works when `--` is the first argument after the script path, but `--` itself must survive PowerShell's parameter binder to reach `$RemainingArgs`, which is the root of the problem.

**AI Suggested Improvement:**
- Add `[CmdletBinding()]` attribute and use `--%` (stop-parsing token) before CLI arguments; document that `./b4w.ps1 --% snapshot -i` is the canonical invocation for short flags
- Alternatively, add explicit `-SnapshotArgs` parameter that accepts a single quoted string: `./b4w.ps1 -SnapshotArgs "snapshot -i"`
- Update `b4w.ps1` top help (lines 92-125) to explicitly warn about short-flag interception and give the exact workaround
- Consider renaming the script's own `-Rebuild` to `--rebuild` (double-dash) to reduce namespace collision with PowerShell common parameters
