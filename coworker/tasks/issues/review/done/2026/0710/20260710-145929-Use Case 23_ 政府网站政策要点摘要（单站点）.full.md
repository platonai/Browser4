### Issue 3: `press Enter` on search textbox triggers form GET instead of JS search handler

**Severity:** Medium

**Category:** Reliability

**Reproduction:**
```
cargo run --manifest-path cli/browser4-cli/Cargo.toml -- goto "https://www.gov.cn/"
cargo run --manifest-path cli/browser4-cli/Cargo.toml -- type "人工智能" e340

```
**Expected:** Pressing Enter on the search textbox should execute the same search as clicking the search button — opening the search results at `sousuo.www.gov.cn`.

**Actual:** The page reloads to `https://www.gov.cn/?t=govall&headSearchword=...` (the form's GET action). The JavaScript `goSearch()` function (which opens `window.open(..., '_blank')` to the actual search) is not triggered.

**Root Cause:** The gov.cn page uses both a `<form>` with a GET action and a JavaScript `onkeyup` handler (`listenerKeyUpEventFn`). `press Enter` triggers the browser's native form submission (GET to current page + query params) rather than the JS `keyup` event handler that calls `goSearch()`. The `press` command likely dispatches a `keydown`/`keyup` event that doesn't fully replicate native browser Enter behavior in the context of this specific page's JS event handling.

**Code Pointer:** `cli/browser4-cli/src/` — the `press` command's Enter key simulation. May need to ensure it triggers both `keypress` events and the form's submit event in a way that allows JS `preventDefault()` to intercept, or to check whether the page has an `onkeyup`/`onkeydown` handler and trigger that path.

**AI Suggested Improvement:**
- After `press Enter` on a textbox inside a form, detect whether the page navigated to the form's action URL vs. a different URL — if the form action was used but there's a search button present, suggest clicking the button instead
- Document in the help/skill that `press Enter` on forms with complex JS behavior may not work; recommend finding and clicking the submit button
- Add a `--submit` flag to `type`/`fill` that clicks the nearest submit button after entering text instead of relying on Enter key behavior
