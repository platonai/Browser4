**Severity:** Medium

**Category:** UX / Discoverability

**Expected:** A clear, discoverable separation between the accessibility-tree snapshot (for interaction refs) and the HTML snapshot (for content extraction). Ideally, a single entry point or a naming convention that makes the distinction obvious.

**Actual:** `snapshot` captures an accessibility tree for element interaction refs. `htmlsnapshot` captures a static HTML page for CSS-selector-based extraction. Both have `grep` subcommands, both produce "snapshots," and the relationship between them is not immediately clear from the help output. A new user reading the help will see both and wonder which to use.

**Root Cause:** The command namespace conflates two different snapshot technologies under similar names. The SKILL.md documents the distinction in the decision tree (§4a), but the CLI help output doesn't make the distinction clear.
