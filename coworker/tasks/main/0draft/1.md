## Enhance snapshot to provide more options

The `snapshot` command supports filtering to reduce output size:

```bash
browser4-cli snapshot                    # Full accessibility tree
browser4-cli snapshot -i                 # Interactive elements only (buttons, inputs, links)
browser4-cli snapshot -i --urls          # Interactive elements with link URLs
browser4-cli snapshot -c                 # Compact (remove empty structural elements)
browser4-cli snapshot -d 3               # Limit depth to 3 levels
browser4-cli snapshot -s "#main"         # Scope to CSS selector
browser4-cli snapshot -i -c -d 5         # Combine options
```

| Option                 | Description                                                             |
| ---------------------- | ----------------------------------------------------------------------- |
| `-i, --interactive`    | Only show interactive elements (buttons, links, inputs)                 |
| `-u, --urls`           | Include href URLs for link elements                                     |
| `-c, --compact`        | Remove empty structural elements                                        |
| `-d, --depth <n>`      | Limit tree depth                                                        |
| `-s, --selector <sel>` | Scope to CSS selector                                                   |
