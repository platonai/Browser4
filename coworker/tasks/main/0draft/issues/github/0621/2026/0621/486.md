# `cargo run` instructions do not specify the correct working directory

URL: https://github.com/platonai/Browser4/issues/486
State: OPEN
Author: galaxyeye
Assignees: galaxyeye
Created: 06/21/2026 14:40:32
Updated: 06/21/2026 14:43:09

**Severity:** Low
**Category:** Documentation

## Summary

Task documentation instructs users to run `cargo run -- help` without specifying the working directory where `Cargo.toml` is located. Since `Cargo.toml` resides in `cli/browser4-cli/`, not in the repository root or the test scenarios directory, users encounter a "Cargo.toml not found" error when following this instruction.

## Steps to Reproduce

1. Follow task instructions that say "Run `cargo run -- help`."
2. Execute the command from the current working directory (e.g., the test scenarios directory or repository root).

## Expected Behavior

The command succeeds, or the documentation specifies the correct directory (`cli/browser4-cli/`).

## Actual Behavior

The command fails because `Cargo.toml` is not found in the current directory. The `Cargo.toml` for the CLI is located at `cli/browser4-cli/Cargo.toml`.

## Suggested Fix

- Update task instructions and the repository README to specify that `cargo run` commands should be executed from the `cli/browser4-cli/` directory.
- Alternatively, document that users can install the CLI globally via `cargo install --path cli/browser4-cli` and use `browser4-cli` directly, avoiding the `cargo run` path issue entirely.
