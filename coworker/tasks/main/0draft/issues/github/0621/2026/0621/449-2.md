# Prices displayed in HKD with no currency/locale override option

## Summary

When navigating to Amazon.com via browser4-cli, search results may display prices in Hong Kong Dollars (HKD) rather than the expected USD. The browser inherits the geo-detected locale, and there is no way to override the location or currency setting from the CLI.

## Steps to reproduce

1. Run `browser4-cli open https://www.amazon.com/`.
2. Perform a search.
3. Observe the prices displayed in search results.

## Expected behavior

Prices should be displayed in the expected currency (e.g., USD on amazon.com), or at minimum there should be a way to specify a preferred locale.

## Actual behavior

Amazon detects the user's location (e.g., Hong Kong) and displays prices in HKD. While this is Amazon's behavior rather than a browser4-cli bug, it affects data quality for users expecting prices in a specific currency.

## Suggested resolution

- Document that browser4-cli inherits the browser's geo-detected locale and that price display depends on Amazon's regional behavior.
- Consider adding a locale or country override option to the `open` or `goto` commands, potentially via query parameters or headers.
