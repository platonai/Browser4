# `summarize` agent command times out

URL: https://github.com/platonai/Browser4/issues/483
State: OPEN
Author: galaxyeye
Assignees: galaxyeye
Created: 06/21/2026 14:39:23
Updated: 06/21/2026 14:43:21

**Severity:** High
**Category:** Bug / Reliability

## Summary

The `browser4-cli summarize` command consistently times out before returning results. This means the AI-powered page summarization feature is effectively unusable in its current configuration.

## Steps to Reproduce

1. Navigate to a product page with substantial content.
2. Run: `browser4-cli summarize "What are the main pros and cons?"`

## Expected Behavior

An AI-generated summary of the page content is returned within a reasonable timeframe.

## Actual Behavior

`Error: HTTP request timed out [tool=agent_summarize, timeout=30s]`

## Suggested Fix

- Increase the default timeout for AI-powered commands to accommodate realistic response times.
- Provide a fallback mechanism (e.g., partial results or a "still processing" status) instead of a hard failure.
- Document the expected response latency so users know what to anticipate.
