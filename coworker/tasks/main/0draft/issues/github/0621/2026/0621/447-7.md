# No `--timeout` global option documented

## Summary

There is no configurable timeout option available in the CLI. When users encounter timeout errors (e.g., the 30-second default is too short for many operations), there is no way to configure or extend the timeout via a command-line flag, environment variable, or configuration file.

## Steps to reproduce

1. Encounter a timeout error on any command (e.g., `type`, `fill`, `extract`).
2. Search the help output, SKILL.md, or error messages for timeout configuration.

## Expected behavior

A `--timeout` flag or `BROWSER4_TIMEOUT` environment variable should be available to configure command timeout.

## Actual behavior

No timeout configuration option is found in help output, SKILL.md, or error messages. The 30-second default timeout is hardcoded and too short for many operations, particularly AI-based commands like `extract`.

## Suggested resolution

- Add a global `--timeout=<ms>` option that applies to all commands.
- Document the `--timeout` option in the help output and SKILL.md.
- Consider supporting a `BROWSER4_TIMEOUT` environment variable as an alternative configuration mechanism.
- Set a more generous default timeout (at least 60-120 seconds) for commands known to require longer execution (e.g., `extract`).
