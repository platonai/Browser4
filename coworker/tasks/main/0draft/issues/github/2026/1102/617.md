Hey, we maintain HOL Guard. Would you submit a browser4 extension to HOL Guard so an AI agent can ask for approval before that deletion? Your README describes `uninstall` as "Remove global installs and runtime data. Supports `-y`, `--yes`, and `--dry-run`".

A first PR can cover just `uninstall`: one rule, one approval-required test, and one read-only test. The [extension builder and PR checklist](https://github.com/hashgraph-online/hol-guard/blob/main/docs/guard/extension-builder/README.md#prepare-a-complete-pull-request) walk through generating starting files from saved CLI help, reviewing them, and submitting your PR to `hashgraph-online/hol-guard`. No changes to this repo or its CI are needed. The extension stays off unless a user enables it.
