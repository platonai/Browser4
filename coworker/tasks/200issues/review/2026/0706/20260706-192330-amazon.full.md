### Issue 1: Auto-discover (htmlsnapshot inspect) defaults to generic selectors, not product cards

**Severity:** Medium

**Category:** UX

**Reproduction:**
```
cargo run -- htmlsnapshot inspect
```
On an Amazon search results page.

**Expected:** The auto-discovery should identify `.s-result-item[data-component-type='s-search-result']` as the primary repeating pattern and suggest product-specific selectors (titles, prices, ratings).

**Actual:** The auto-discovery analyzed `div#a-page` and navigation elements, suggesting generic selectors like `div` and `span`. A separate targeted `inspect` call with the specific container selector was needed to discover product-level selectors.

**Root Cause:** The auto-discovery algorithm picks the first repeating element from `:root`. On Amazon, the navigation keyboard shortcuts divs and page-level containers are found first. **Code Pointer:** Likely in the `htmlsnapshot inspect` implementation — the container-priority heuristic.

**AI Suggested Improvement:**
- Prioritize containers with consistent child structure (image + heading + price pattern) over navigation elements
- When multiple repeating patterns exist, surface all of them with labels (e.g., "Navigation items", "Product cards", "Footer links")
- Add a `--category` or `--pattern` flag to hint at the type of repeating element being sought

### Issue 2: Documentation's recommended CSS selectors fail on non-English Amazon locale

**Severity:** Medium

**Category:** Documentation

**Reproduction:**
1. Navigate to amazon.com (which auto-detects locale and may serve Chinese UI to Singapore visitors)
2. Follow scenario 15b from `htmlsnapshot-scenarios-amazon.md`
3. Run `htmlsnapshot get all text "h2 a.a-link-normal"`

**Expected:** Product titles should be returned.

**Actual:** The selector `h2 a.a-link-normal` returns an empty array `[]`. The working selector on this locale is `a.a-link-normal.s-line-clamp-4`.

**Root Cause:** Amazon serves different HTML structures depending on the detected locale. The page was served in Chinese (简体中文) for a Singapore-based browser. The `h2` wrapper around product title links is absent in this locale variant, replaced by a flat `a` tag with `s-line-clamp-4` class.

**Code Pointer:** `skills/browser4-cli/references/htmlsnapshot-scenarios-amazon.md` — scenario 15b selector recommendations.

- Add a warning in scenario 15b that CSS selectors vary by Amazon locale, and show fallback selectors for common locale variants
- Include `a.a-link-normal.s-line-clamp-4` as an alternative title selector in the documentation
- Suggest using `htmlsnapshot inspect ".s-result-item[data-component-type='s-search-result']"` as the first step to discover locale-specific selectors, rather than assuming the documented selectors will work

The main friction points are: (1) locale-dependent CSS selectors that require trial-and-error discovery, (2) verbose `htmlsnapshot` output that could benefit from better grouping/prioritization, and (3) snapshot viewport management requiring manual calculation for content-aware capture. These are refinement issues rather than fundamental problems — the core extraction pipeline works reliably and efficiently.
