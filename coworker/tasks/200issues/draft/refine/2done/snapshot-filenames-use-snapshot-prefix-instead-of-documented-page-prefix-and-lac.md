# Snapshot filenames use `snapshot-` prefix instead of documented `page-` prefix and lack milliseconds

The actual snapshot filenames generated by the tool do not match the format documented in SKILL.md, which can confuse first-time users comparing their output to the documentation.

**Steps to reproduce:**
1. Run any snapshot-producing command.
2. Compare the generated filename to what SKILL.md shows.

**Expected behavior:** Filenames follow the pattern shown in docs: `page-2026-02-14T19-22-42-679Z.yml`

**Actual behavior:** Filenames use the pattern `snapshot-2026-06-25T17-48-34Z.yml` — the prefix is `snapshot-` not `page-`, and the timestamp lacks milliseconds.

**Suggested improvement:** Update the code to match the documented format, or update the documentation to match the actual output.
