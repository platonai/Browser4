## Issue #2: Snapshots can be too large to read in a single operation

**Severity:** High
**Category:** Product / UX
**Reproduction:** Navigate to any content-heavy page (e.g., Amazon search results), take a snapshot. Try to Read the resulting YAML file.
**Expected:** Snapshot is readable in a single Read call, or there is a built-in pagination/filtering mechanism.
**Actual:** The search results snapshot was 480KB (>256KB read limit) and 512+ lines. Required multiple chunked reads and text search to find products.
**Suggested Improvement:** (a) Raise the default Read limit for snapshot files, or (b) Add a `--limit-products=N` or `--search-results` mode to snapshots that only returns product-card subtrees, or (c) Provide a `snapshot read <file> --offset/--limit` built-in command.
