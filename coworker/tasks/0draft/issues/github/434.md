## Summary

The `click` command's behavior with cross-domain links is not documented in the help output or SKILL.md. Users navigating through sites like Hacker News — where every story link points to an external domain — will encounter unexpected timeouts with no prior warning or guidance in the documentation.

## Description

When clicking a link that navigates from one domain to another (e.g., from news.ycombinator.com to an external article domain), the `click` command times out despite the navigation succeeding. This behavior is not mentioned anywhere in:

- `browser4-cli help` output
- `browser4-cli help click` command-specific help
- SKILL.md documentation
- README.md

A user following the documented workflow of "snapshot -> find ref -> click ref" on a site with external links will encounter this timeout with no indication that the issue is specific to cross-domain navigation.

## Related Issues

- Click command timeout on cross-domain navigation (core bug)
- Click timeout reports failure despite successful navigation (misleading feedback)

## Suggested Improvements

- Document in `help click` and SKILL.md that cross-domain navigation via `click` is currently unreliable and may time out
- Document any known workarounds (e.g., using `goto` with the target URL as a fallback)
- Add troubleshooting guidance for timeout errors on cross-domain links
