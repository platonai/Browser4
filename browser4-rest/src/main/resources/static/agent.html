            提示没有 LLM / API key？
            
后端需要配置一个模型 Key 才能跑任务。在启动后端的终端里设置环境变量之一，然后重启后端：

            
DEEPSEEK_API_KEY · OPENROUTER_API_KEY · VOLCENGINE_API_KEY · OPENAI_API_KEY

          


          

            它到底在哪儿开浏览器？我能看到吗？
            
任务由本机后端执行。后端默认可能以无头模式运行浏览器，所以你看不到窗口，但可以打开顶部的
              页面截图 看它当前在哪个页面；
              也可以用 browser4-cli open --headed 之后重新提交，让浏览器带界面启动。

          


          

            它要写文件 / 跑命令，会先问我吗？
            
不会。网页控制台按无人值守策略提交，没有逐项审批环节；权限由后端的
              browser4.agent.access.unattended 决定（默认 full，工作区边界和敏感路径仍然有效）。
              要每个敏感操作都经你同意，请在终端用：

            
browser4-cli agent run -i "你的任务"

            
运行中会用 /approve 让你确认每次授权。

          


          

            这个页面和终端 agent run -i 是什么关系？
            
同一个后端、同一套会话记忆。页面做了 -i 最常用的几件事：提交任务、实时看步骤、
              插话、停止、读结果。终端里 -i 的横幅会打印带会话的网页地址，
              两边可以接着同一个会话继续聊；/goal、/approve 等高级命令仍在终端。

          


          

            会话是什么？为什么要记住它？
            
会话就是它和你的对话上下文：同一个会话里的下一个任务会带着上文，比如「把刚才那 5 条整理成表格」。
              会话 ID 在左边「会话、连接」里，也可以贴进终端：agent run -i -s <会话 ID>。

          


          

            结果里的文件在哪里？
            
任务写出的文件路径会出现在结果里；「工作目录」就是它这次写盘的地方。
              浏览类任务通常只返回结论，不写文件。
