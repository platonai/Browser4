# visual-screenshot-controls

1. Resize the browser viewport to 1280 by 900 pixels.
2. Go to `https://en.wikipedia.org/wiki/Large_language_model`.
3. Wait for the page to reach the network idle state before proceeding.
4. Take a default screenshot to capture the current viewport.
5. Scroll down several times to load more of the article content.
6. Wait for any new content to appear (e.g., wait for a specific section heading text to be visible).
7. Take a full-page screenshot that captures the entire article from top to bottom. Save it with a custom filename.
8. Scroll back up to the top of the page.
9. Wait 2 seconds to let any animations settle, then take another screenshot at the top.
10. Save the page as a PDF with a custom filename.
