# session-management

1. Open a named session called "research" and navigate to `https://en.wikipedia.org/wiki/Browser_automation`.
2. Open a second named session called "news" and navigate to `https://news.ycombinator.com`.
3. Take a snapshot in the "news" session to verify you are on Hacker News.
4. Switch back to the "research" session and take a snapshot to verify you are on the Wikipedia article.
5. List all active browser sessions with full details to see both named sessions.
6. Close the "news" session.
7. List sessions again to confirm only the "research" session remains.
8. Close all remaining sessions to finish.
