# navigation-basics

1. Go to `https://en.wikipedia.org/wiki/Web_scraping`.
2. Take a snapshot of the page to see the accessible elements.
3. Identify a link in the "See also" section and click it to navigate to that article.
4. Use the browser's history navigation to go back to the Web scraping article, then go forward again to the linked article.
5. Reload the current page to refresh its content.
6. Check the overall status of the browser4-cli backend server.
7. List all active browser sessions to see what is running.
8. Close the current session to end the task cleanly.
