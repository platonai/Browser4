Meridian Kettle — Spec Sheet

The Meridian is a 1.7 litre variable-temperature kettle. This page is the reference sheet: the two paragraphs below are the article body, and the nav above and the footer below are the noise a readability pass is expected to drop.

It ships in three variants, listed in the table further down. The temperature can be set in 5 °C steps between 40 °C and 100 °C, which is the feature most reviews lead with.

Reading the temperature

Set the target and read it back. The call is synchronous; the kettle reports the temperature it actually reached, not the one requested, so callers should compare rather than assume:

val kettle = Meridian.connect()
kettle.target = 85
check(kettle.current in 80..90) { "expected the kettle to reach the target" }

Boiling is not adjustable above 100 °C at sea level; the kettle holds at a rolling boil instead.

Notes

  • Descale every 4–6 weeks in hard-water areas.
    • Citric acid, 1 tablespoon per litre.
  • The base is not dishwasher safe.
  1. Fill to the minimum mark.
  2. Set the target temperature.
  3. Press Start; the ring turns amber.
