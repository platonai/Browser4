## 三、关键发现

1. **温度数据一致**：两个网站对上海当前最高温度（32℃）的报道一致。
2. **天气状况基本一致**：阴天为主，明后两天有小雨/中雨。
3. **湿度数据差异**：weather.com.cn 提供的是「过去24小时最大相对湿度」（90%），而 tianqi.qq.com 提供的是当前湿度（79%），数据维度不同导致数值差异。
4. **风力趋势一致**：两个网站都预测明天（11日）风力增强至5-6级，这与台风"巴威"预警相符。
5. **tianqi.qq.com 信息更丰富**：提供了气压（999hPa）、AQI（41 优）、台风预警、逐小时预报、生活指数等更多维度数据。
6. **weather.com.cn 温度数据更完整**：为每天提供了明确的高温/低温数值，而 tianqi.qq.com 的页面结构使得 CSS 选择器提取温度数据较为困难。

## 四、数据提取过程说明

### weather.com.cn
- 使用直接 URL 导航：`https://www.weather.com.cn/weather/101020100.shtml`
- 通过 `htmlsnapshot get all text` + CSS 选择器（`.sky`, `.tem`, `.wea`, `.win`）批量提取
- 首页搜索框为 JavaScript 自动补全组件，`press Enter` 无法触发表单提交

### tianqi.qq.com
- 通过搜索框填入「上海」+ 匹配下拉建议完成城市切换
- 页面使用 AJAX 动态更新，搜索后 URL 不变
- CSS 选择器提取困难（AX tree 中的 class 名称与 DOM 中不一致）
- 数据主要从 `snapshot grep` 输出的 accessibility tree 中手动解析
